# Security Policy

## Reporting Vulnerabilities
If you discover a security vulnerability or Cross-Site Scripting (XSS) issue with SVG rendering, please report it privately:
* **Contact:** Open a private GitHub Security Advisory at [https://github.com/manjurgowda777/Design-APP/security/advisories](https://github.com/manjurgowda777/Design-APP/security/advisories)
* Please do not disclose vulnerabilities publicly in issues until a patch is released.
